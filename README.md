# Social Brand Designer

Mini Next.js app for designing monochromatic social covers and profile photos.

- Local JSON database at `data/db.json`
- Uploaded DP stored in `data/assets/`
- Live mockups for LinkedIn, X, Facebook, YouTube, Instagram
- Modern vCard QR (name, phones, emails, socials, custom links)
- ZIP export for covers or covers + DP

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
